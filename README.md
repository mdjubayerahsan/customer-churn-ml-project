# Customer Churn Prediction Project

## Objective
This project aims to predict whether a customer will churn using machine learning techniques.

## Dataset
Telco Customer Churn Dataset from Kaggle

## Steps Performed
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Encoding
- Model Building

## Models Used
- Logistic Regression (~78%)
- Decision Tree (~72%)
- Random Forest (~79%)

## Best Model
Random Forest performed the best with highest accuracy.

## Key Insights
- Month-to-month customers are more likely to churn
- Customers with high monthly charges churn more
- New customers have higher churn rate

## Tools Used
Python, Pandas, Seaborn, Scikit-learn, Google Colab
